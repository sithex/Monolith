## Design and behavior

Switch: 44×24 px by default, 34×20 px small; 20/16 px knobs. OFF uses `--v-track` plus `--v-stroke-hi`; ON crossfades an accent overlay over 200 ms using `--dur-base`. `--switch-knob` derives neutral white once through relative OKLCH from `--ui-accent`, remaining white on both tones; a neutral shade derived in the same colour space supplies the 12 px inset shadow and subtle knob shadow. There are no literal colours in switch.css.

The real checkbox has `role="switch"`, `className="switch"`, native checked/change/disabled/focus/Space behavior and forwarded input props. The framer motion span uses `initial={false}` with no re-key. Changes take 260 ms ease-out with no delay, using full transform keyframes for travel and squish (20→28→20 wide, 20→14→20 high) rather than animating layout dimensions. Press feedback widens the knob slightly. Tracking the previous committed value in an effect keeps memo rendering pure under StrictMode. Keyboard navigation and either reduced-motion source settle instantly; CSS also stops in-flight transforms when modality/preference changes. Disabled opacity is .4.

DraftRange: real native range input retained inside `.pill-range`; original draft, throttle, `live={false}`, external-value protection and final commit logic retained. Pointer-cancel now also forwards the supplied callback. The wrapper exposes a clamped 0–1 `--fill-ratio`. A 14 px resting pill grows to 20 px with scaleY inside a reserved 20 px row. Full-thickness accent fill uses scaleX with left origin; a 3 px grip stays visible/inset at both ends. Direct dragging has no interpolation; other value changes use `--dur-base` ease-out, with instant keyboard/reduced-motion behavior. Focus outlines use `--ui-focus`; disabled opacity is .4.

Fader: the existing 40×160 px box and its padding/min/max sizing remain; the inner pill is 36 px wide with a 12 px radius. Fill rises through scaleY from the bottom, desaturating to `--ui-text-hint` when muted. `.fader-thumb` remains a 3 px horizontal grip with the actual percentage in `style.bottom`; its transform keeps it inside the pill at the endpoints. Hover/drag slightly widens the track. Pointer following stays direct, with the existing throttle, wheel math, keyboard bounds, capture and ARIA. `.fader-col`, `.fader-name`, `.fader-pct` and the mute icon/button are preserved.

Both CSS files use theme tokens; no design-token exception was needed. Existing color-picker internals, Dropdown, VoiceControls and ControlsApp were not edited. No dependencies, Rust, contracts, deployment or push changes.
